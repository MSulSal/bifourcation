# Bifourcation

Draw a path. Watch it split into rotating oriented planes.

Bifourcation is an interactive Fourier drawing app built around geometric algebra. It looks like a Fourier epicycle toy at first, but the visual language is intentionally different: the app does not present the reconstruction as “complex numbers in an imaginary plane.” Instead, it treats the drawing surface as a real oriented plane generated by `e₁` and `e₂`, with `e₁e₂` as the bivector that drives rotation.

## What it does

- Draw freehand strokes on a canvas.
- Choose stroke color and pen width.
- Convert each stroke into an evenly sampled path.
- Compute Fourier terms for each stroke.
- Animate each stroke in order.
- Preserve completed stroke reconstructions while later strokes animate.
- Visualize Fourier components as oriented blades or companion vectors.
- Export/share snapshots of the current reconstruction.

## Why this exists

Most Fourier drawing demos use complex numbers and epicycles. Those are mathematically valid, but they can make rotation feel like it happens in a mysterious “imaginary” place.

Bifourcation uses geometric algebra instead:

```txt
v = x e₁ + y e₂

e₁v = e₁(x e₁ + y e₂)
    = x e₁² + y e₁e₂
    = x + y e₁e₂
```
